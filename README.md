# PIZZA-SALES-DASHBOARD-ANALYSIS
## Project Overview

The **Pizza Sales Analysis** project is an end-to-end data analytics project designed to analyze pizza sales data and transform raw transactional data into meaningful business insights.

The project uses **SQL** for querying and KPI analysis, **Python** for data analysis and exploration, and **Powerbi** for building an interactive business intelligence dashboard.

The analysis focuses on understanding:

* Overall business performance
* Customer ordering behaviour
* Daily and monthly sales trends
* Pizza category performance
* Pizza size preferences
* Best-selling products
* Low-performing products
* Revenue and order patterns

### Key questions addressed:

1. How much revenue did the business generate?
2. How many orders were placed?
3. How many pizzas were sold?
4. What is the average value of each order?
5. How many pizzas are purchased per order?
6. Which days receive the highest number of orders?
7. Which months perform best?
8. Which pizza categories contribute the most revenue?
9. Which pizza sizes are most popular?
10. Which pizzas are the highest and lowest performers?
11. What sales patterns can help improve business decisions?
